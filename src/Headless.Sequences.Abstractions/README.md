# Headless.Sequences.Abstractions

Defines the tenant-scoped sequence contracts: `ISequenceGenerator`, `SequenceRange`, and the gap-free `unit.Sequences` accessor.

## Why use this package

Lets application code take receipt, invoice, or case numbers without referencing a database provider.

## Install

```bash
dotnet add package Headless.Sequences.Abstractions
```
