# Headless.Coordination.Sqlite

Stores coordination membership in SQLite with server-clock liveness.

## Why use this package

Provides an authoritative SQLite membership provider for multi-instance apps that already depend on a SQLite primary.

## Install

```bash
dotnet add package Headless.Coordination.Sqlite
```
