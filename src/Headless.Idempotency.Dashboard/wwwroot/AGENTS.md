# Idempotency dashboard module

This is the Idempotency module of the unified dashboard. Follow the dashboard front-end rules in [src/Headless.Dashboard/wwwroot/AGENTS.md](../../Headless.Dashboard/wwwroot/AGENTS.md): they cover formatting, code style, the no-CSS rule, data honesty, performance, and tests for every module. The module's screen and endpoints are documented in [docs/llms/dashboards/idempotency-module.md](../../../docs/llms/dashboards/idempotency-module.md).

Check a change with `make dashboard-idempotency-test`, and format with `make dashboards-format`.
