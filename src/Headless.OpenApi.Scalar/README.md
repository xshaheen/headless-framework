# Headless.OpenApi.Scalar

Scalar API documentation UI integration — renders the OpenAPI documents served by `MapOpenApi()` as an interactive browser-based UI.

## Why use this package

The native OpenAPI generator serves JSON only. This package mounts Scalar as the documentation UI at a configurable endpoint, pre-configured with sensible defaults (dark mode, alphabetical tag sorting, method-based operation sorting, and a curated set of code generation targets and HTTP clients).

## Install

```bash
dotnet add package Headless.OpenApi.Scalar
```
