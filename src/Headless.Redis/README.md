# Headless.Redis

Redis utilities and Lua script management for StackExchange.Redis.

## Why use this package

Provides Redis helper extensions plus definition-first Lua script loading/execution for StackExchange.Redis. Each script loads on its first use, so no startup preload is needed.

## Install

```bash
dotnet add package Headless.Redis
```
