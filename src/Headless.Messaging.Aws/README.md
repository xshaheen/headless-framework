# Headless.Messaging.Aws

Amazon SNS bus and SQS queue transport provider for the messaging system.

## Why use this package

Enables bus fan-out through SNS topics and queue work delivery through SQS queues, with the topics, queues, policies, and subscriptions created by the `resources provision` deploy step.

## Install

```bash
dotnet add package Headless.Messaging.Aws
```
