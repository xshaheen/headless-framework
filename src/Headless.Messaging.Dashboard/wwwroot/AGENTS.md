# Messaging dashboard module

This is the Messaging module of the unified dashboard. Follow the dashboard front-end rules in [src/Headless.Dashboard/wwwroot/AGENTS.md](../../Headless.Dashboard/wwwroot/AGENTS.md): they cover formatting, code style, the no-CSS rule, data honesty, performance, and tests for every module. The module's screens and endpoints are documented under "Messaging module" in [docs/llms/dashboards.md](../../../docs/llms/dashboards.md).

Check a change with `make dashboard-messaging-test`, and format with `make dashboards-format`.
