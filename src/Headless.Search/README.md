# Headless.Search

Defines the versioned Arabic search rules and a C# normalizer that applies them.

## Why use this package

Provides `ArabicSearchNormalizer`, `ArabicSearchRuleSet`, and `AddHeadlessSearch`, so a database provider can build stored search keys with the same rules your code uses to highlight matches, without binding to a database.

## Install

```bash
dotnet add package Headless.Search
```
