Live queries bench

Three queries on this page are open streams. Every command you send commits on the server, and the server re-sends only the queries that read what the commit wrote. Open this page in a second window to watch one window's commands update the other, then switch one window to another owner.

Bench settings

With latency on, turn optimistic updates off and on to compare. An optimistic row carries a "saving" chip until this window's own stream reports the command's id.

Todos

Waiting for the first result.

    The list reads one owner's rows, and the owner of a todo never changes. A write for another owner therefore does not run this list again; the count above reads every todo and always runs.
